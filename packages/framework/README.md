Elegant and lightweight PHP framework for modern web applications.

## Get started

Use PHP 8.2 or later and Composer 2.

```bash
composer require codemonster-ru/annabel
```

## Documentation

For full framework documentation, visit [Annabel getting started guide](https://docs.codemonster.net/annabel/getting-started).
