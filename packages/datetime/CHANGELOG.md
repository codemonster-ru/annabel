# Changelog

## [1.0.0] - 2026-07-31

- Added immutable date-time parsing, formatting, arithmetic, and comparisons.
- Added explicit timezone conversion and calendar boundary operations.
- Added week and quarter arithmetic, strict date/time setters, ranges, and min/max comparisons.
- Added ICU date formatting and English/Russian human-readable intervals.
- Added configurable business calendars with weekends and holidays.
- Added PSR-20 system and frozen clocks.
