# Contributing

Development takes place in the [Annabel monorepo](https://github.com/codemonster-ru/annabel), in the
[packages/scheduler directory](https://github.com/codemonster-ru/annabel/tree/main/packages/scheduler). Open issues and pull requests in the monorepo.
Follow the [Annabel contribution guide](https://github.com/codemonster-ru/annabel/blob/main/CONTRIBUTING.md)
for setup, checks, and commit subjects.

Report suspected vulnerabilities through the [security policy](https://github.com/codemonster-ru/annabel/blob/main/SECURITY.md).
